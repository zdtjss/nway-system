# nway-system 文件管理对接文档

> 适用对象：需要接入 nway-system 文件中心的外部系统（前端 / 后端）
> 版本：2026-11，基于当前实现（本地磁盘存储、短时票据、`@nway/file` SDK）
> 能力范围：单文件上传、元数据查询、下载、图片/视频/PDF 预览、逻辑删除

## 1. 能力概览

文件中心向两类调用方提供能力：

| 调用方 | 鉴权方式 | 接口前缀 | 典型场景 |
| --- | --- | --- | --- |
| 平台登录用户 | 用户 JWT | `/nway-system/file/**` | 平台管理页、平台内业务表单 |
| 外部系统 | 开放平台 App Token | `/nway-system/open/file/**` | 外部系统上传附件、查询/下载文件 |

能力清单：

- 单文件上传（`multipart/form-data`），服务端校验大小、扩展名白名单与文件名。
- 文件元数据分页查询、按 ID 查询、逻辑删除。
- 下载（`attachment`）与预览（`inline`），支持 HTTP Range（视频拖动进度）。
- 图片、视频、PDF 在线预览，其他类型下载。
- 浏览器 `<img>` / `<video>` 无法携带 Header，通过短时票据访问。
- 前端 SDK：`@nway/file`（零运行时依赖客户端）+ `@nway/file/vue`（Vue 3 组件）。

**当前版本限制**

- 仅支持单文件上传，不支持分片上传、断点续传与秒传。
- 未实现病毒扫描、图片压缩、缩略图与视频转码。
- 未实现文件版本、回收站与物理文件定时清理。
- 存储层当前仅实现本地磁盘，S3/MinIO 为预留扩展点。
- 开放接口不支持删除文件，删除仅由平台管理页执行。

**基础信息**

- 服务地址：`http://<host>:8081`（本地 profile 默认 `9081`）
- 上下文路径：`/nway-system`（下文接口均基于该前缀）
- 统一响应格式（文件流接口除外）：

```json
{
  "code": 200,
  "msg": null,
  "data": {}
}
```

## 2. 接入准备

### 2.1 初始化 `sys_file` 表

`sys_file` 已包含在 `db/migration/09_file_tables.sql` 中，按 README 顺序执行迁移脚本即可；存量库如需单独补表，可执行以下 DDL：

```sql
CREATE TABLE sys_file (
  id            VARCHAR(32)  PRIMARY KEY,
  tenant_code   VARCHAR(20)  NOT NULL,
  file_name     VARCHAR(255) NOT NULL COMMENT '原始文件名，仅用于展示',
  storage_type  VARCHAR(16)  NOT NULL DEFAULT 'local' COMMENT '存储引擎：local/s3',
  storage_key   VARCHAR(512) NOT NULL COMMENT '服务端生成的相对路径',
  file_size     BIGINT       NOT NULL COMMENT '字节数',
  content_type  VARCHAR(128) COMMENT '服务端判定的安全 MIME',
  file_ext      VARCHAR(32)  COMMENT '小写扩展名',
  sha256        VARCHAR(64)  COMMENT '文件 SHA-256 摘要',
  biz_type      VARCHAR(64)  COMMENT '业务类型，如 factoryVisitApply',
  biz_id        VARCHAR(64)  COMMENT '业务单据 ID',
  remark        VARCHAR(255),
  creator_id    VARCHAR(10),
  creator_name  VARCHAR(50),
  modifier_id   VARCHAR(10),
  modifier_name VARCHAR(50),
  create_time   DATETIME,
  modified_time DATETIME,
  is_deleted    BIT DEFAULT b'0',
  INDEX idx_file_tenant_time (tenant_code, create_time),
  INDEX idx_file_biz (biz_type, biz_id),
  INDEX idx_file_sha256 (sha256)
) COMMENT='文件元数据';
```

### 2.2 服务端配置

```yaml
spring:
  servlet:
    multipart:
      max-file-size: ${FILE_MAX_SIZE:200MB}
      max-request-size: ${FILE_MAX_REQUEST_SIZE:220MB}

nway:
  file:
    # 新上传使用的存储引擎；读操作按记录上的 storage_type 路由
    storage-type: ${FILE_STORAGE_TYPE:local}
    # 业务校验上限（字节），必须不大于 multipart 上限
    max-size: ${FILE_MAX_BYTES:209715200}
    # 允许上传的扩展名（逗号分隔，不带点，大小写不敏感）
    allowed-extensions: >-
      jpg,jpeg,png,gif,webp,bmp,
      mp4,webm,ogg,
      pdf,doc,docx,xls,xlsx,ppt,pptx,txt,csv,zip,rar,7z
    # 预览/下载票据有效期（秒）
    ticket-ttl-seconds: ${FILE_TICKET_TTL:600}
    # 外部系统跨域直连时的来源白名单（逗号分隔，支持通配）；留空表示不开放跨域
    cors-allowed-origins: ${FILE_CORS_ORIGINS:}
    local:
      # 必须在 Web 静态目录之外；多实例部署时须挂共享持久卷
      root: ${FILE_STORAGE_ROOT:./data/files}
    s3:
      # 预留扩展点，当前版本未实现
      enabled: false
      endpoint: ${FILE_S3_ENDPOINT:}
      bucket: ${FILE_S3_BUCKET:}
      access-key: ${FILE_S3_ACCESS_KEY:}
      secret-key: ${FILE_S3_SECRET_KEY:}
```

必须同步调整部署侧限制：

- Nginx / 网关 `client_max_body_size` 不小于 220MB。
- Docker / K8s 为 `FILE_STORAGE_ROOT` 挂持久卷。
- 多实例部署时本地磁盘必须是共享卷，否则改用 S3/MinIO。

### 2.3 开放平台应用授权

外部系统在管理端「系统管理 → 开放平台」创建应用后，按需勾选：

| Scope | 用途 |
| --- | --- |
| `file:read` | 查询、获取元数据、下载、预览 |
| `file:write` | 上传文件、申请预览/下载票据（票据接口为 POST，按 scope 推导规则归入 `file:write`） |

开放平台 Token 的获取方式见《外部系统对接文档.md》第 3 节。开放接口不支持删除文件。

### 2.4 跨域配置（浏览器直连时）

外部系统前端跨域直连 nway-system 时，需配置：

```yaml
nway:
  file:
    cors-allowed-origins: https://oa.example.com,https://*.example.com
```

已显式暴露 `Content-Disposition`、`Content-Range`、`Accept-Ranges` 响应头，前端才能读取文件名与分段信息。生产环境建议同源反向代理，避免开放 CORS。

## 3. 接口说明

### 3.1 内部接口（用户 JWT）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/file/upload` | 登录用户 | 上传文件，`multipart/form-data` |
| GET | `/file/queryPage` | `file:view` | 分页查询元数据 |
| GET | `/file/getById?id=` | `file:view` | 按 ID 查询元数据 |
| GET | `/file/download/{id}` | 登录用户 | 下载文件，`Content-Disposition: attachment` |
| GET | `/file/preview/{id}` | 登录用户 | 内联预览，`Content-Disposition: inline` |
| POST | `/file/ticket` | 登录用户 | 生成短时预览/下载票据 |
| GET | `/file/ticketDownload?ticket=` | 票据校验 | 浏览器直链、`<img>`、`<video>` 使用 |
| POST | `/file/delete` | `file:delete` | 逻辑删除元数据 |

说明：

- 上传/下载/预览对登录用户开放，租户隔离由 `sys_file.tenant_code` 自动保证。
- 删除仅逻辑删除元数据，物理文件保留，由后续清理任务统一处理。

### 3.2 开放接口（App Token）

| 方法 | 路径 | Scope | 说明 |
| --- | --- | --- | --- |
| POST | `/open/file/upload` | `file:write` | 上传文件 |
| GET | `/open/file/query` | `file:read` | 分页查询元数据 |
| GET | `/open/file/get/{id}` | `file:read` | 按 ID 查询元数据 |
| GET | `/open/file/download/{id}` | `file:read` | 下载 |
| GET | `/open/file/preview/{id}` | `file:read` | 内联预览 |
| POST | `/open/file/ticket` | `file:write` | 生成短时票据（POST 按 scope 推导规则归入 `file:write`） |

开放 Token 只能调用 `/open/*` 接口；用户 JWT 不能调用 `/open/*` 接口。应用身份一律从 Token 解析，不接受请求头中的应用标识。

### 3.3 上传

```http
POST /nway-system/file/upload
Authorization: Bearer <token>
Content-Type: multipart/form-data

file=<二进制>
bizType=contract        # 可选，业务类型，≤64 字符
bizId=1001              # 可选，业务单据 ID，≤64 字符
remark=合同扫描件        # 可选，≤255 字符
```

服务端校验顺序：

1. 文件非空、文件名长度 ≤255、清洗路径与控制字符。
2. 文件大小 ≤ `nway.file.max-size`（默认 200MB）。
3. 扩展名必须在 `nway.file.allowed-extensions` 白名单内。
4. 按扩展名映射服务端安全 MIME，不信任客户端 `Content-Type`。
5. 生成存储 key：`{tenantCode}/{yyyy}/{MM}/{uuid}.{ext}`，不使用原始文件名拼路径。
6. 先落盘，再写 `sys_file`；数据库写入失败时补偿删除已落盘文件。
7. 计算并保存 SHA-256。

响应 `data` 为 `FileVo`：

```json
{
  "id": "a1b2c3d4e5f6",
  "fileName": "现场照片.jpg",
  "fileSize": 204800,
  "contentType": "image/jpeg",
  "fileExt": "jpg",
  "bizType": "factoryVisitApply",
  "bizId": "FV20261105001",
  "remark": null,
  "creatorId": "EMP001",
  "creatorName": "张三",
  "createTime": "2026-11-10 10:00:00",
  "downloadUrl": "/nway-system/file/download/a1b2c3d4e5f6",
  "previewUrl": "/nway-system/file/preview/a1b2c3d4e5f6"
}
```

`downloadUrl` / `previewUrl` 为相对上下文路径，浏览器直连时仍需携带 `Authorization` Header；`<img>` / `<video>` 请改用票据地址。

### 3.4 查询

内部接口：

```http
GET /nway-system/file/queryPage?fileName=合同&bizType=contract&creatorId=EMP001&current=1&size=15
Authorization: Bearer <token>
```

开放接口：

```http
GET /nway-system/open/file/query?fileName=合同&current=1&size=15
Authorization: Bearer <access_token>
```

查询参数：

| 参数 | 说明 |
| --- | --- |
| `fileName` | 文件名模糊匹配 |
| `bizType` | 业务类型精确匹配 |
| `creatorId` | 上传人工号精确匹配 |
| `startTime` / `endTime` | 上传时间范围，格式 `yyyy-MM-dd HH:mm:ss` |
| `current` / `size` | 页码 / 每页条数 |

响应 `data`：

```json
{
  "data": [
    {
      "id": "a1b2c3d4e5f6",
      "fileName": "现场照片.jpg",
      "fileSize": 204800,
      "contentType": "image/jpeg",
      "fileExt": "jpg",
      "bizType": "factoryVisitApply",
      "bizId": "FV20261105001",
      "creatorId": "EMP001",
      "creatorName": "张三",
      "createTime": "2026-11-10 10:00:00",
      "downloadUrl": "/nway-system/file/download/a1b2c3d4e5f6",
      "previewUrl": "/nway-system/file/preview/a1b2c3d4e5f6"
    }
  ],
  "total": 1
}
```

### 3.5 下载 / 预览与 HTTP Range

```http
GET /nway-system/file/download/{id}
Authorization: Bearer <token>
Range: bytes=0-1023        # 可选
```

响应头：

| 响应头 | 说明 |
| --- | --- |
| `Content-Type` | 服务端按扩展名映射；未知类型为 `application/octet-stream` |
| `Content-Disposition` | 下载 `attachment`，预览 `inline`；中文名使用 RFC 5987 |
| `Accept-Ranges` | 固定 `bytes` |
| `Content-Range` | 分段响应时返回，如 `bytes 0-1023/204800` |
| `X-Content-Type-Options` | `nosniff` |

- 带 `Range` 且合法：返回 `206 Partial Content`。
- `Range` 非法或越界：返回 `416`，并带 `Content-Range: bytes */<total>`。
- 不带 `Range`：返回 `200` 全量内容。
- 视频播放必须使用支持 Range 的地址，否则无法拖动进度。

### 3.6 短时票据

用途：浏览器原生 `<img>`、`<video>`、`<a>` 无法携带 `Authorization` Header。

```http
POST /nway-system/file/ticket
Authorization: Bearer <token>
Content-Type: application/x-www-form-urlencoded

id=a1b2c3d4e5f6&purpose=preview
```

开放接口为 `POST /nway-system/open/file/ticket`，参数相同。

响应：

```json
{
  "ticket": "3xY...（不透明随机串）",
  "url": "/nway-system/file/ticketDownload?ticket=3xY...",
  "expiresIn": 600
}
```

使用：

```html
<img src="http://host/nway-system/file/ticketDownload?ticket=3xY..." />
<video src="http://host/nway-system/file/ticketDownload?ticket=3xY..." controls></video>
```

约束：

- 票据是不透明随机串，不是 JWT，不包含用户身份明文。
- 票据绑定单个文件与租户，有效期内可重复使用（视频 Range 会发多次请求）。
- 默认有效期 600 秒，由 `nway.file.ticket-ttl-seconds` 配置。
- 过期后重新申请；前端组件在加载失败时会自动重试一次。
- 票据只出现在 URL 中，JWT 不允许放进 URL。

## 4. 前端接入

文件上传/预览的客户端与 Vue 组件属于**纯前端能力**，完整说明见：

- [文件上传与预览前端能力](../../nway-system-web/docs/文件上传与预览.md)

要点：

- 平台内通过 Vite alias `@nway/file` / `@nway/file/vue` 引用 `nway-system-web/packages/file`，无需发布 npm 包。
- 外部系统可复用同一 SDK：用户态传 `mode: 'internal'` + 用户 JWT，应用态传 `mode: 'open'` + 开放平台 Token。
- 上传使用 XHR（进度、取消），查询/下载/票据使用 fetch；多媒体预览通过 `createTicket` 获取短时票据地址。
- 具体 Props、事件、上传校验、预览交互与常见问题在前端文档中维护，本文只描述后端接口与协议。

## 5. 安全与约束

| 风险 | 措施 |
| --- | --- |
| 目录穿越 | `storageKey` 服务端生成；落盘前归一化并校验仍在根目录 |
| 恶意文件 | 扩展名白名单；未知类型按 `application/octet-stream` 下载 |
| MIME 伪造 | 服务端按扩展名映射安全 MIME，不直接使用客户端 `Content-Type` |
| XSS | 图片预览仅位图格式；SVG 默认禁止预览；`X-Content-Type-Options: nosniff` |
| 越权下载 | 租户隔离 + 文件 ID 不可枚举 + 票据绑定文件与租户 |
| 凭据泄露 | JWT 只走 Header；URL 只放短时票据，不放 JWT |
| 大文件打满磁盘 | 大小上限 + 配额 + 定期清理孤儿文件 |
| 视频拖动 | 后端支持 Range，前端 `<video>` 依赖 206 |
| 跨域 | 明确 CORS 白名单与暴露响应头；或同源反向代理 |

补充说明：

- 上传接口对登录用户开放，不要求单独的 `file:create` 权限；如需限制上传，可在网关或业务侧控制。
- 开放接口不支持删除文件，删除仅由平台管理页执行。
- 逻辑删除后元数据不再返回，物理文件由后续清理任务处理。

## 6. 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 上传返回 413 | Nginx / 网关 `client_max_body_size` 小于文件大小 |
| 上传提示“文件大小超过限制” | `nway.file.max-size` 或 `spring.servlet.multipart.max-file-size` 配置过小 |
| 上传提示“不支持的文件类型” | 扩展名不在 `nway.file.allowed-extensions` 中 |
| `<img>` / `<video>` 403 | 票据过期、票据与文件不匹配，或未使用 `ticketDownload` 地址 |
| 视频无法拖动进度 | 下载地址未返回 `Accept-Ranges: bytes` / `206`，或中间代理未透传 `Range` |
| 外部系统跨域失败 | 未配置 `nway.file.cors-allowed-origins`，或代理未放行 `Authorization` / `Range` |
| 文件下载后中文名乱码 | 代理丢弃或改写了 `Content-Disposition`，需确保透传 |
| 多实例上传后另一实例下载 404 | 本地存储未使用共享卷，需挂共享卷或切换 S3/MinIO |
