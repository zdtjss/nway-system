# 子应用页签打开能力

> 适用对象：接入 nway-system 的微前端子应用（wujie / micro-app / iframe）前端开发者
> 能力目标：子应用点击业务单据时，由平台**以页签方式**打开目标页面，全程不新开浏览器标签，并复用平台登录态

## 1. 能力说明

平台承载的子应用可以请求宿主以页签方式打开一个页面，行为与用户在平台内点击菜单完全一致。典型场景：流程列表点击一条单据，在平台页签中打开该单据的详情页。

| 运行环境 | 行为 |
| --- | --- |
| 平台内（wujie / micro-app / iframe） | 宿主新增页签并打开目标页面，当前应用保持原状 |
| 非平台环境 / 宿主未接入该通道 | 返回 `false`，由子应用自行降级（如页内 iframe、路由跳转） |

页签关闭后，宿主会回到打开它的来源页签，并通知来源页签刷新数据（`nway:page-activated`）。

---

## 2. 快速接入

### 2.1 打开页面

将以下代码原样保存为子应用内的 `src/utils/openInHost.js`：

```js
/**
 * 在 nway-system 平台内以「页签」方式打开目标页面。
 *
 * 平台（宿主）以 wujie / micro-app / iframe 三种方式承载本应用，对应通道：
 *  - 同源 iframe（wujie 沙箱、微前端 -iframe 降级）：宿主暴露的全局入口 window.$nway
 *  - wujie（跨域等取不到父窗口）：与宿主共享的 EventBus（window.$wujie.bus）
 *  - micro-app：向宿主发送全局数据（window.microApp.setGlobalData）
 *  - 跨域 iframe：window.parent.postMessage
 *
 * 后三条通道均需宿主回执（`nway:open-page-ack`）确认已受理；未回执说明宿主未接入该通道，
 * 返回 false 由调用方降级，避免在非平台环境或平台未升级时点击无任何反馈。
 *
 * 宿主侧统一由 nway-system-web 的 src/js/subAppBridge.js 收口，
 * 最终调用平台页签能力（useCurrentPageStore.showPage + 跳转 /main）。
 */

const OPEN_PAGE_EVENT = 'nway:open-page'

const OPEN_PAGE_ACK_EVENT = 'nway:open-page-ack'

/** 宿主回执等待时间：超时视为宿主未接入，由调用方降级为页内 iframe 页签 */
const ACK_TIMEOUT = 300

/**
 * 本应用当前的渲染方式：作为目标页面的 renderType 回传宿主，
 * 使同一平台内打开的子应用与本应用渲染方式一致。
 */
function currentRenderType() {
    if (window.$wujie) {
        return window.$wujie.degrade ? 'wujie-iframe' : 'wujie'
    }
    if (window.microApp || window.__MICRO_APP_ENVIRONMENT__) {
        // micro-app 有两种渲染模式：WebComponent（默认）与 iframe 沙箱（<micro-app iframe>）。
        // 由 micro-app 注入的 __MICRO_APP_SANDBOX_TYPE__ 区分（'with' / 'iframe'），
        // 未注入（未启用沙箱）时按 WebComponent 处理。
        return window.__MICRO_APP_SANDBOX_TYPE__ === 'iframe' ? 'microApp-iframe' : 'microApp'
    }
    if (window.self !== window.top) {
        return 'iFrame'
    }
    return ''
}

/**
 * 是否运行在 nway-system 平台内：平台会通过 wujie props / micro-app data 注入登录态，
 * 并把用户 Token 存入 sessionStorage（key: ds-token）。
 * 仅凭 wujie / micro-app 环境变量不足以判定（其它微前端宿主也会提供），
 * 故非平台宿主时不走微前端通道，直接返回 false 由调用方降级。
 */
function isNwayHost() {
    const payload = (window.$wujie && window.$wujie.props) || (window.microApp && window.microApp.getData && window.microApp.getData())
    if (payload && (payload.token || payload.user)) {
        return true
    }
    try {
        return !!sessionStorage.getItem('ds-token')
    } catch (e) {
        return false
    }
}

/**
 * 请求宿主以页签方式打开页面。
 *
 * @param {{ name?: string, url: string }} menu 页签名称与目标地址（须为 http/https 完整地址，平台据此判定为外部子应用）
 * @returns {Promise<boolean>} 是否已交由平台打开；false 表示不在平台内或宿主未接入该通道，调用方应自行降级
 */
export async function openPageInHost(menu) {
    if (!menu || !menu.url) {
        return false
    }
    const payload = {
        type: OPEN_PAGE_EVENT,
        menu: {
            name: menu.name || '详情',
            url: menu.url,
            type: 'PAGE',
            renderType: currentRenderType(),
        },
    }

    // 同源 iframe（wujie 沙箱、微前端 -iframe 降级）：父窗口的全局入口可直接确认宿主已接入
    try {
        const hostWindow = window.parent !== window ? window.parent : null
        if (hostWindow && hostWindow.$nway && typeof hostWindow.$nway.openPage === 'function') {
            hostWindow.$nway.openPage(payload.menu)
            return true
        }
    } catch (e) {
        // 跨域 iframe 访问父窗口被拒，走后面的通道
    }

    // wujie：与主应用共享的 EventBus
    if (isNwayHost() && window.$wujie && window.$wujie.bus && typeof window.$wujie.bus.$emit === 'function') {
        const bus = window.$wujie.bus
        return await sendWithAck(payload, {
            listen: (onPayload) => {
                if (typeof bus.$on !== 'function') return null
                bus.$on(OPEN_PAGE_ACK_EVENT, onPayload)
                return () => typeof bus.$off === 'function' && bus.$off(OPEN_PAGE_ACK_EVENT, onPayload)
            },
            send: (data) => bus.$emit(OPEN_PAGE_EVENT, data),
        })
    }

    // micro-app：向主应用发送全局数据（宿主 addGlobalDataListener 接收）
    if (isNwayHost() && window.microApp && typeof window.microApp.setGlobalData === 'function') {
        const microApp = window.microApp
        return await sendWithAck(payload, {
            listen: (onPayload) => {
                if (typeof microApp.addGlobalDataListener !== 'function') return null
                microApp.addGlobalDataListener(onPayload)
                return () => typeof microApp.removeGlobalDataListener === 'function' && microApp.removeGlobalDataListener(onPayload)
            },
            send: (data) => microApp.setGlobalData(data),
        })
    }

    // 跨域 iframe：postMessage（仅传递页签信息，不含任何业务数据）
    if (window.parent !== window) {
        return await sendWithAck(payload, {
            listen: (onPayload) => {
                const onMessage = (event) => onPayload(event && event.data)
                window.addEventListener('message', onMessage)
                return () => window.removeEventListener('message', onMessage)
            },
            send: (data) => window.parent.postMessage(data, '*'),
        })
    }

    return false
}

/**
 * 发送请求并等待宿主回执。
 *
 * @param {object} payload 请求载荷（自动附加 requestId）
 * @param {{ listen?: (onPayload: Function) => (Function|null), send: (data: object) => void }} channel
 *        listen 注册回执监听并返回取消监听函数（无该能力时返回 null）
 */
function sendWithAck(payload, { listen, send }) {
    return new Promise((resolve) => {
        const requestId = 'nway-open-page-' + Date.now() + '-' + Math.random().toString(16).slice(2)
        let timer = null
        let unlisten = null

        const done = (opened) => {
            if (timer) clearTimeout(timer)
            if (typeof unlisten === 'function') unlisten()
            resolve(opened)
        }

        function onPayload(data) {
            if (data && data.type === OPEN_PAGE_ACK_EVENT && data.requestId === requestId) {
                done(true)
            }
        }

        timer = setTimeout(() => done(false), ACK_TIMEOUT)
        if (typeof listen === 'function') {
            unlisten = listen(onPayload)
        }
        try {
            send(Object.assign({}, payload, { requestId }))
        } catch (e) {
            done(false)
        }
    })
}
```

调用方式：

```js
import { openPageInHost } from '@/utils/openInHost'

async function openDetail(row) {
  const opened = await openPageInHost({
    name: row.subject || row.no || '详情', // 页签名称
    url: row.detailsUrl,                  // 必须是 http(s) 完整地址
  })

  if (!opened) {
    // 非平台环境或宿主未接入：在这里做自己的降级
    // 例如 router.push(...) 或打开应用内 iframe 页签
  }
}
```

- 同源 iframe 通道可立即确认宿主已受理，返回 `true`；其余通道最多等待宿主 300ms 回执。
- 未收到回执即返回 `false`，不会抛出异常，可直接在点击事件中调用，无需阻塞用户操作。

### 2.2 关闭当前页签（可选）

被打开的子应用提交完成后，按平台约定请求关闭自己所在的页签。将以下代码原样保存为 `src/utils/closePage.js`：

```js
/**
 * 关闭当前页面。
 *
 * 默认自动探查运行环境：
 *  - 运行在 nway-system 下（wujie / micro-app / iframe 三种承载）：走宿主菜单关闭通道，
 *    由宿主按 renderType 销毁实例并移除页签；
 *  - 其它环境：执行调用方传入的自定义关闭函数。
 *
 * 关闭请求只携带当前页面地址，宿主按地址找到对应菜单后沿用自身关闭逻辑，
 * 子应用不直接操作 wujie / micro-app / iframe 实例。
 *
 * wujie / micro-app 通道需宿主回执（nway:close-page-ack）确认已受理；
 * 跨域 iframe 无法读取父窗口，只能通过 postMessage 探测，收到回执即视为宿主支持菜单关闭。
 */

const CLOSE_PAGE_EVENT = 'nway:close-page'

const CLOSE_PAGE_ACK_EVENT = 'nway:close-page-ack'

/** 宿主回执等待时间：超时视为宿主未接入，转自定义关闭 */
const ACK_TIMEOUT = 300

/**
 * 关闭当前页面。
 *
 * @param {() => void | Promise<void>} [customClose] 非 nway-system 环境下的自定义关闭（缺省为 window.close）
 * @returns {Promise<boolean>} 是否已交由 nway-system 关闭
 */
export async function closePage(customClose) {
  const menu = {
    url: currentPageUrl(),
    name: document.title || '',
  }

  if (await closeInNwaySystem(menu)) {
    return true
  }

  if (typeof customClose === 'function') {
    await customClose()
  } else {
    window.close()
  }
  return false
}

/**
 * 当前页面地址。
 *
 * micro-app 沙箱（含 iframe 模式）会把子应用的 location 改写为「宿主域名 + 子应用路径」，
 * 直接用 location.href 上报会让宿主按地址找不到已打开的菜单（菜单记录的是子应用真实地址），
 * 因此优先取 micro-app 注入的应用入口地址。
 */
function currentPageUrl() {
  if (window.__MICRO_APP_ENVIRONMENT__ && window.__MICRO_APP_URL__) {
    return window.__MICRO_APP_URL__
  }
  return window.location.href
}

/**
 * 自动探查 nway-system 的承载方式并请求关闭当前菜单/页签。
 *
 * @param {{ url: string, name: string }} menu 当前页面地址与名称
 * @returns {Promise<boolean>} 宿主是否已受理
 */
async function closeInNwaySystem(menu) {
  // 同源 iframe（wujie 沙箱、微前端 -iframe 降级、页内 iframe）：父窗口全局入口可直接确认
  try {
    const hostWindow = window.parent !== window ? window.parent : null
    if (hostWindow && hostWindow.$nway && typeof hostWindow.$nway.closePage === 'function') {
      hostWindow.$nway.closePage(menu)
      return true
    }
  } catch (e) {
    // 跨域 iframe 读取父窗口被拒，继续走消息通道
  }

  const payload = { type: CLOSE_PAGE_EVENT, menu }

  // wujie：宿主通过 props 注入平台登录态时才视为 nway-system
  if (isNwayWujieHost() && window.$wujie.bus && typeof window.$wujie.bus.$emit === 'function') {
    const bus = window.$wujie.bus
    const closed = await sendWithAck(payload, {
      listen: (onPayload) => {
        if (typeof bus.$on !== 'function') return null
        bus.$on(CLOSE_PAGE_ACK_EVENT, onPayload)
        return () => typeof bus.$off === 'function' && bus.$off(CLOSE_PAGE_ACK_EVENT, onPayload)
      },
      send: (data) => bus.$emit(CLOSE_PAGE_EVENT, data),
    })
    if (closed) {
      return true
    }
  }

  // micro-app：宿主通过 data 注入平台登录态时才视为 nway-system
  if (isNwayMicroAppHost() && typeof window.microApp.setGlobalData === 'function') {
    const microApp = window.microApp
    const closed = await sendWithAck(payload, {
      listen: (onPayload) => {
        if (typeof microApp.addGlobalDataListener !== 'function') return null
        microApp.addGlobalDataListener(onPayload)
        return () => typeof microApp.removeGlobalDataListener === 'function'
          && microApp.removeGlobalDataListener(onPayload)
      },
      send: (data) => microApp.setGlobalData(data),
    })
    if (closed) {
      return true
    }
  }

  // 跨域 iframe：读不到父窗口全局入口，发送关闭协议探测；收到回执说明宿主支持菜单/页签关闭
  if (window.parent !== window) {
    const closed = await sendWithAck(payload, {
      listen: (onPayload) => {
        const onMessage = (event) => onPayload(event && event.data)
        window.addEventListener('message', onMessage)
        return () => window.removeEventListener('message', onMessage)
      },
      send: (data) => window.parent.postMessage(data, '*'),
    })
    if (closed) {
      return true
    }
  }

  return false
}

/** nway-system 下 wujie 会通过 props 注入 token / user */
function isNwayWujieHost() {
  const props = window.$wujie && window.$wujie.props
  return !!(props && (props.token || props.user))
}

/** nway-system 下 micro-app 会通过 data 注入 token / user */
function isNwayMicroAppHost() {
  if (!window.microApp || typeof window.microApp.getData !== 'function') {
    return false
  }
  const data = window.microApp.getData()
  return !!(data && (data.token || data.user))
}

/**
 * 发送关闭请求并等待宿主回执。
 *
 * @param {object} payload 请求载荷（自动附加 requestId）
 * @param {{ listen?: (onPayload: Function) => (Function|null), send: (data: object) => void }} channel
 *        listen 注册回执监听并返回取消监听函数（无该能力时返回 null）
 * @returns {Promise<boolean>} 宿主是否已受理
 */
function sendWithAck(payload, { listen, send }) {
  return new Promise((resolve) => {
    const requestId = `nway-close-page-${Date.now()}-${Math.random().toString(16).slice(2)}`
    let timer = null
    let unlisten = null

    const done = (closed) => {
      if (timer) clearTimeout(timer)
      if (typeof unlisten === 'function') unlisten()
      resolve(closed)
    }

    function onPayload(data) {
      if (data && data.type === CLOSE_PAGE_ACK_EVENT && data.requestId === requestId) {
        done(true)
      }
    }

    timer = setTimeout(() => done(false), ACK_TIMEOUT)
    if (typeof listen === 'function') {
      unlisten = listen(onPayload)
    }
    try {
      send(Object.assign({}, payload, { requestId }))
    } catch (e) {
      done(false)
    }
  })
}
```

调用方式：

```js
import { closePage } from '@/utils/closePage'

async function submit() {
  await save()
  // 平台内：宿主关闭当前页签并回到来源页签
  // 非平台：执行传入的自定义关闭（这里返回列表页）
  await closePage(() => router.replace('/list'))
}
```

### 2.3 页签重新激活后刷新（可选）

来源页签在“由它打开的页签”被关闭后会收到通知，用于刷新列表等数据。以下代码兼容 wujie / micro-app / 纯 iframe：

```js
const PAGE_ACTIVATED_EVENT = 'nway:page-activated'

/** 仅当确实从本页打开过页签时才刷新，避免普通切换页签也发请求 */
let pendingRefresh = false

function onPageActivated() {
  if (!pendingRefresh) return
  pendingRefresh = false
  loadList() // 换成你的列表加载方法
}

/** 订阅「页签重新激活」，返回取消订阅函数 */
function listenPageActivated() {
  const wujie = window.$wujie
  if (wujie && wujie.bus && typeof wujie.bus.$on === 'function') {
    // wujie：宿主按 appName 定向发送，appName 由平台通过 props 注入
    const appName = wujie.props && wujie.props.appName
    const eventName = appName ? `${PAGE_ACTIVATED_EVENT}:${appName}` : PAGE_ACTIVATED_EVENT
    wujie.bus.$on(eventName, onPageActivated)
    return () => typeof wujie.bus.$off === 'function' && wujie.bus.$off(eventName, onPageActivated)
  }

  if (window.microApp) {
    // micro-app：监听保活应用重新显示（aftershow）
    const onAppStateChange = (event) => {
      if (event && event.detail && event.detail.appState === 'aftershow') onPageActivated()
    }
    window.addEventListener('appstate-change', onAppStateChange)
    return () => window.removeEventListener('appstate-change', onAppStateChange)
  }

  // 纯 iframe：监听宿主 postMessage
  const onMessage = (event) => {
    if (event && event.data && event.data.type === PAGE_ACTIVATED_EVENT) onPageActivated()
  }
  window.addEventListener('message', onMessage)
  return () => window.removeEventListener('message', onMessage)
}
```

打开页签前置位 `pendingRefresh = true`，宿主未受理时复位：

```js
async function openDetail(row) {
  pendingRefresh = true
  if (await openPageInHost({ name: row.subject || row.no, url: row.detailsUrl })) {
    return
  }
  pendingRefresh = false
  // 执行自己的降级逻辑
}
```

## 3. 通信协议

### 3.1 通道与回执

`openPageInHost({ name, url })` 依次尝试 4 条通道，命中即返回：

| 顺序 | 承载方式 | 判定条件 | 子应用发送方式 | 回执 |
| --- | --- | --- | --- | --- |
| 1 | 同源 iframe（wujie 沙箱 / `-iframe` 降级） | `window.parent.$nway.openPage` 为函数 | `parent.$nway.openPage(menu)` | 同步确认，无需回执 |
| 2 | wujie | 平台内且 `window.$wujie.bus.$emit` 存在 | `bus.$emit('nway:open-page', payload)` | 监听 `nway:open-page-ack` |
| 3 | micro-app | 平台内且 `window.microApp.setGlobalData` 存在 | `microApp.setGlobalData(payload)` | 监听 globalData |
| 4 | 跨域 iframe | `window.parent !== window` | `parent.postMessage(payload, '*')` | 监听 `message` |

回执等待时间 `ACK_TIMEOUT = 300ms`，超时视为宿主未接入，返回 `false`，由调用方降级。

### 3.2 消息载荷

```json
{
  "type": "nway:open-page",
  "requestId": "nway-open-page-1730000000000-a1b2c3",
  "menu": {
    "name": "报销申请-张三",
    "url": "https://app-oa.example.com/apply/detail?bizId=123",
    "type": "PAGE",
    "renderType": "wujie"
  }
}
```

- `requestId` 由发送方自动生成，宿主在回执中原样带回，用于匹配请求，防止误判。
- `renderType` 回传子应用当前渲染方式，使宿主打开的新页签与当前应用一致，取值：`wujie` / `wujie-iframe` / `microApp` / `microApp-iframe` / `iFrame` / `''`。
- 跨域 `postMessage` 只传页签信息，不含任何业务数据。
- 关闭页签使用同样的载荷结构，仅 `type` 为 `nway:close-page`，回执为 `nway:close-page-ack`。

### 3.3 平台判定 `isNwayHost()`

满足任一条件即认为运行在 nway-system 平台内：

- wujie `props` 或 micro-app `getData()` 中存在 `token` 或 `user`；
- `sessionStorage` 存在 `ds-token`。

仅凭 `$wujie` / `microApp` 全局变量不足以判定，避免把其它微前端宿主误当成平台。

## 4. 宿主侧收口

宿主侧实现位于 `nway-system-web/src/js/subAppBridge.js`，在 `nway-system-web/src/App.vue` 中安装一次：

```js
import { installSubAppBridge } from '@/js/subAppBridge'

installSubAppBridge(openPage, closePage)
```

- 打开回调等价于平台内点击菜单：`currentPageStore.showPage(menu)` + `currentPageStore.setShowIndex(false)` + `router.push('/main')`。
- 打开时把当前页签地址记录为来源页签 `openedFrom`；关闭该页签后回到来源页签，并调用 `notifyPageActivated` 通知其刷新。
- 关闭按页面地址定位页签（忽略 hash 与末尾斜杠），子应用只需上报 `{ url, name }`，不直接操作 wujie / micro-app / iframe 实例。
- 子应用未指定 `renderType` 时，宿主按平台默认的 `microApp` 处理。
- 保活实例重新显示后，`nway-system-web/src/views/current.vue` 会补发一次 `nway:page-activated`，避免隐藏期间监听被清空导致通知丢失。

## 5. 约束与注意事项

1. **`url` 必须是 http(s) 完整地址**：平台据此判定为外部子应用，相对路径会打开空白页。
2. **回执超时 300ms**：宿主未升级或未接入时不阻塞用户操作，直接降级；新增通道时须保持同样的超时降级语义。
3. **平台内判断不能只看微前端全局变量**：必须结合平台注入的 `token` / `user` / `ds-token`，否则第三方宿主会被误判。
4. **URL 不传 token**：子应用登录态统一由平台通过 wujie `props` / micro-app `data` 注入；纯 iframe 走 `nway:auth-request` / `nway:auth` 握手。
5. **宿主与子应用协议需成对修改**：`openInHost.js`、`closePage.js`、`subAppBridge.js`、`current.vue` 中的事件名与回执格式必须一致。
6. **micro-app 的重新激活通知不复用 globalData**：改听 `appstate-change`（`aftershow`），避免与打开 / 关闭回执共用全局数据导致 `type` 互相覆盖。
